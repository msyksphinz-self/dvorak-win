# Dvorak-Win

Windows 用の常駐型 Dvorak 配列リマッパーです。日本語 IME (ローマ字入力) と JIS キーボードで使うことを前提にしています。
DvorakJ などの既存ツールで起きがちな「いつの間にか効かなくなる」「落ちる」問題を、仕組みの側で潰すことを目標にしています。

- 単一の exe (約 450KB, ランタイム不要)。インストール不要で、置いて起動するだけ
- タスクトレイ常駐 (青い D = 有効, 灰色の D = 無効/一時停止)
- 設定はテキストファイル (`dvorak-win.ini`) 1 つ

## 「効かなくなる」への対策

| よくある原因 | このツールでの対策 |
| --- | --- |
| フックの処理が遅いと Windows が**黙ってフックを外す** (LowLevelHooksTimeout) | フック専用スレッドを最高優先度で動かし、コールバックでは I/O をしない。さらに数秒ごとにフックを付け直すので、外されても自動で復旧する |
| スリープ復帰・画面ロック解除・リモート接続のあとに効かない | 電源/セッションの通知を受けて、状態をリセットしフックを付け直す |
| **管理者権限のウィンドウ** (タスクマネージャー、管理者ターミナル等) で効かない | 「管理者権限で再起動」と、タスクスケジューラでの管理者権限自動起動を用意 |
| Windows 11 の効率モード (EcoQoS) でバックグラウンド処理が間引かれる | 自プロセスの電源スロットリングを無効化し、優先度を「通常以上」に |
| タスクスケジューラ既定の「3 日で停止」「バッテリー時は起動しない」「優先度: 低」 | 自動起動の登録時にすべて無効化し、異常終了時は 1 分後に自動再起動 |
| エクスプローラー再起動でトレイアイコンが消えて操作できない | TaskbarCreated を受けてアイコンを再登録 |
| Shift を一時的に離す処理で、IME が「Shift 単独押し」と判定して**英数モードに切り替わる** | Shift の再押下を必要になるまで遅らせ、ダミーキーを挟んで単独押し判定を回避 |
| 想定外のエラーで落ちる | コールバック内のパニックは捕捉し、そのキーは素通しにする |

## 使い方

1. `dvorak-win.exe` を好きなフォルダに置いて起動します (初回起動時に同じフォルダに `dvorak-win.ini` が作られます)。
2. トレイアイコンを**左クリック**で有効/無効を切り替え、**右クリック**でメニューを開きます。
3. ホットキー `Ctrl+Shift+F12` でも切り替えられます。

### おすすめ設定: 管理者権限で自動起動

右クリックメニューの「**ログオン時に自動起動 (管理者権限)**」にチェックを入れてください (UAC の確認が出ます)。
これでタスクマネージャーなどの管理者権限のウィンドウでも Dvorak が効くようになります。
今すぐ管理者権限に切り替えたいときは「管理者権限で再起動」を選びます。

DvorakJ を併用すると二重に変換されるので、DvorakJ は終了・自動起動を解除してください。

## 設定 (`dvorak-win.ini`)

```ini
[general]
enabled = true
; これらを押している間は QWERTY のまま (Ctrl+C/V/X/Z を従来の位置で)。全部 Dvorak にするなら none
qwerty_shortcuts = ctrl, alt, win
toggle_hotkey = Ctrl+Shift+F12
rehook_interval_ms = 3000
; Dvorak を適用しないアプリ (例: リモートデスクトップ先で別の配列を使う場合)
exclude = mstsc.exe

[layout]
; 物理キー (US QWERTY の刻印名) = 通常時の文字  Shift時の文字
q = ' "
w = , <
...
```

`[layout]` は「物理キーの位置 → 出したい**文字**」で書きます。文字を打つためのキー (JIS では `'` は Shift+7 など) は OS のキーボード配列から自動で求めるので、JIS キーボードでも US Dvorak の記号配置がそのまま使えます。
数字段の記号も US 式にしたい場合は `2 = 2 @` のように追加してください。編集後はメニューの「設定を再読み込み」で反映されます。

## ビルド

```sh
cargo test                       # 変換ロジックの単体テスト (どの OS でも可)
cargo build --release            # Windows 上で
# Linux からクロスビルドする場合
rustup target add x86_64-pc-windows-gnu   # + mingw-w64
cargo build --release --target x86_64-pc-windows-gnu
```

GitHub Actions で push のたびに Windows 版をビルドし、成果物 (Artifacts) として exe をダウンロードできます。`v*` タグを push するとリリースも作成されます。

## 構成

- `src/engine.rs` … キー変換の状態機械 (OS 非依存・単体テストあり)
- `src/layout.rs` / `src/config.rs` … 配列定義と設定ファイルの解析
- `src/win/hook.rs` … 低レベルキーボードフック、SendInput、フックの自動付け直し
- `src/win/app.rs` … トレイ、ホットキー、前面アプリ監視、電源/セッション通知
- `src/win/autostart.rs` … タスクスケジューラ登録
